# Prompts Library

## Atomic Task Execution

Read the 10 Project Brain files in the mandatory order from `AI_CONTEXT.md`. Execute only `NEXT_TASK.md`; distinguish planned, configured, deployed, verified, and unknown; run its exact verification commands; then record outcomes without inventing evidence.

Do not expose secrets, change infrastructure without explicit approval, or enter a later stage without an explicit task.

## Review Prompt

Review a proposed change against `AI_CONTEXT.md`, `CURRENT_STATE.md`, `NEXT_TASK.md`, `DECISIONS.md`, and its evidence. Identify scope violations, unsupported claims, secret exposure, missing verification, and required Project Brain updates. Do not modify files unless asked.
