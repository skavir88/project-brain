# Design System

## Status
No design-system implementation is authorized in Stage 0.

## Future Intent
Later, the design system may define accessible enterprise UI foundations, tokens, components, responsive behavior, and presentation rules for Enterprise AI. Those decisions require an explicit Stage 1 task and must not imply an approved UI architecture today.

## Stage 0 Constraint
This document records the boundary only. It does not define visual style, component APIs, implementation, or a production UI.
