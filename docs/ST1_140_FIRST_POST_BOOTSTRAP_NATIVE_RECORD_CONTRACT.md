# ST1-140 — First Post-Bootstrap Native Record Contract

## Purpose

This contract defines the minimum truthful evidence shape for the **first real
post-bootstrap record** from:

- `maroon_project_controls_progress_workbook_series`

under the prospective pilot-governance boundary:

- `governance_bootstrap_effective_from = 2026-08-15`

It is intentionally future-facing. It does **not** reinterpret or upgrade the
historical representative workbook `070-TWRP-24 1402-12-05.xlsx`.

## Scope

This contract applies only to:

- `project_scope = maroon_pilot`
- `candidate_class_id = project_controls_progress_workbook`
- `target_source_id = maroon_project_controls_progress_workbook_series`

It is a **native-record contract**, not an approval by itself.

## Required evidence groups

### 1. Human / governance assertions

These are governance or controlled-source assertions. They are not generated by
runtime:

- prospective A1 governance-owner decision
- prospective A2 accountable role designation
- prospective A3 controlled report-definition designation
- selected-series pilot identifier approval
- source-registration rule / evidence reference
- applicable policy/version selection

### 2. Runtime-generated evidence

These must be generated or observed by the system/runtime path, not asserted by
governance:

- native read-only acquisition timestamp
- source reference used for acquisition
- acquisition method
- original fingerprint / SHA-256
- size and media type
- deterministic transformation timestamp
- transformation tool name/version
- transformation input fingerprint
- transformation output fingerprint
- lineage completeness / deterministic flags

### 3. Business-time evidence

Business/reporting period must resolve only from the approved rule:

- `workbook_labelled_reporting_week_header`
- `designated_reporting_period_field`

Disallowed substitutes remain:

- `row_level_planned_date`
- `row_level_target_date`
- `filesystem_timestamp`
- `acquisition_timestamp`

## Truth boundary

Even if this contract is fully populated, it still does **not** mean:

- historical authority is proven
- current status is known
- certification is done
- reliance eligibility is enabled

It only means the record is shaped correctly to attempt the existing SDAS
preflight and policy path for **new governed evidence**.

## Relationship to the preserved historical workbook

The historical representative workbook remains:

- useful as preserved historical native evidence;
- useful as an example of selected-series structure and reporting-period
  semantics;
- **not** the first post-bootstrap record for the prospective path.

That distinction is mandatory because post-bootstrap governance authority must
not be backfilled onto historical evidence.
